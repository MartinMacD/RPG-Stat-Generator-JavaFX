# RPG Stat Generator (JavaFX)

Basic RPG/Dungeons and Dragons stat generator for rolling the stats of a newly created character.

## Tech Used
Java + JavaFX

## How it works
The player rolls four dice, of these the highest rolled three die are auto selected and the total is displayed.
<br>
The player then chooses one of six stats to apply the total value rolled by the dice to.
<br>
The character can be reset at any time via the reset button.
